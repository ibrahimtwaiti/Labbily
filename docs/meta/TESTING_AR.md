## تغطية الاختبارات الجديدة

الوضع الافتراضي المغلق؛ RBAC وCSRF؛ تشفير الرمز وعدم تسريبه؛ عزل قائمة الربط والاستخدام؛ ربط state بالشركة والمستخدم والجلسة؛ انتهاء state واستخدامه مرة واحدة؛ رفض app_id خاطئ والرمز المنتهي والصلاحيات الناقصة والأصل غير الممنوح؛ إثبات علاقة الرقم؛ منع الاستيلاء على أصل شركة ثانية؛ التسجيل والاشتراك والفصل؛ منع fallback لرمز قديم بعد الفصل؛ تنقيح أخطاء HTTPX؛ عدم تكرار mutation تلقائيًا؛ عدم انعكاس الأسرار في أخطاء التحقق؛ Rate Limit؛ رفض إعداد production وإصدارات غير مراجعة.

اختبارا المتصفح المضافان يتحققان من تعطيل الزر دون إعداد، ومن تجميع code وحدث v5 الصحيح ورفض origin مزور. السيناريو الثاني يستخدم SDK وهميًا ولا يُعد اختبار Embedded Signup حقيقيًا حتى لو نجح في CI.

تُضاف هذه الفحوص إلى workflow القائم. مُنع رفع الفرع إلى GitHub بواسطة المراجعة التلقائية التي طلبت موافقة صريحة على النشر إلى الوجهة الخارجية؛ لذلك لم يُفتح PR ولم تُشغّل CI لهذا التغيير. لا نشر إنتاج ولا اختبار إرسال حقيقي ضمن هذه النتائج.

تعذر تشغيل Chromium النظامي بسبب socket()، ثم نجحت السيناريوهات على Chromium Headless Shell الذي يوفره Playwright. كشفت الجولة الأولى مشكلة حفظ الحقول الاختيارية الفارغة؛ صُححت وأعيدت المجموعة كاملة بنجاح. أُعيدت اختبارات Meta الثلاثة عشر بعد تحسين OpenAPI وإصلاح التحقق.
