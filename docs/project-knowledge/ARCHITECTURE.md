# Architecture and code map
## Observed in main
FastAPI/Python 3.12+ with `index.py` as Vercel entrypoint; `labbily/main.py` app, routing, auth integration. Browser app: HTML/JS/CSS under labbily/static (SPA), no npm runtime frontend framework per package.json. npm tooling for development/checks and Playwright. Requirements include FastAPI, Uvicorn, httpx, psycopg, cryptography, boto3 and PDF processing. Docker/Compose for local persistent alternative. Do not redesign as Next.js or microservices without a migration decision.
- Persistence: `db.py`, SQL migrations, PostgreSQL/Neon in deployed environment; SQLite supported locally. `saas.py`, `entitlements.py`, `security.py`, `privacy.py`, `email_verification.py`, `runtime_configuration.py`, `provider_console.py` handle tenant/business controls.
- Service: `service.py`, `service_api.py`, `service_channels.py`, `service_oauth.py`, `service_templates.py`, `service_media.py`, `service_lifecycle.py`, `service_health.py`, `inbox_workspace.py`; Meta modules `meta_onboarding.py`, `meta_lifecycle.py`, `meta_data.py`, `meta_pages.py`, `page_posts.py`, `messenger_metrics.py`.
- AI: `agent_api.py`, `agent_engine.py`, `agent_jobs.py`, `agent_knowledge.py`, `agent_retrieval.py`; browser agents.js/css. Jobs and worker (`jobs.py`, `worker.py`), Neon function drain/index.mjs. Webhook persisted before ACK; worker processes with retry/dead-letter/idempotency. Verify each path rather than assuming uniform behavior.
- Ops: backup/restore and monitoring scripts; R2 private media and independent backups documented. Vercel production and separate staging; actual project framework fastapi observed.

## Data flow
Channel -> signed webhook -> tenant resolution -> durable event -> worker -> normalized ticket/message -> inbox or eligible agent/flow -> policy, quota, ownership checks -> outbound queue -> provider -> status webhook. Retrieval uses tenant-scoped approved knowledge; actions require authorization and approval where appropriate. Failures must be visible, never fake delivery. This is the documented design, not a proof every path is live.
